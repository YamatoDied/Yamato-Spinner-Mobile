YAMATO SPINNER -> APK ДЛЯ ANDROID (збирається в хмарі, на ПК нічого ставити не треба)

1) Зайди на github.com (безкоштовний акаунт), натисни "New repository", назви як хочеш (можна Private).
2) У новому репозиторії: "uploading an existing file" -> перетягни ВМІСТ цієї папки (index.html лежить у www, а ще package.json,
   capacitor.config.json і прихована папка .github - вона обов'язкова). Натисни "Commit changes".
3) Відкрий вкладку Actions -> "Build APK" -> зелена галочка (~5-8 хв). Якщо не стартувало саме: Run workflow.
4) Відкрий завершений запуск -> внизу "Artifacts" -> YamatoSpinner-apk (це zip з app-debug.apk). Скинь apk на телефон.
5) На телефоні відкрий apk -> дозволь встановлення з цього джерела -> Встановити.

Прогрес зберігається в самому застосунку. Перенос з ПК/на інший телефон - кнопка 💾 всередині гри (як у мобільній версії).
Оновити гру: заміни www/index.html у репозиторії -> збірка піде знову. Кожна збірка підписується новим тимчасовим ключем, тому новий apk
не встановиться поверх старого: СПЕРШУ скопіюй прогрес (💾 -> КОПІЮВАТИ), видали стару гру, постав нову і встав прогрес (💾 -> ЗАВАНТАЖИТИ).
iPhone: apk не підходить; там використовуй варіант "на головний екран" з README-MOBILE.txt.
